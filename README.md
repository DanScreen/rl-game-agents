# rl-game-agents

Training neural networks to play games with reinforcement learning, starting with Atari titles such as Space Invaders and later moving on to board games like chess.

## Goals

- Build reusable RL training pipelines (environment wrappers, agents, training loops, evaluation).
- Start with Atari (Space Invaders) using value-based and policy-gradient methods.
- Extend to chess, using self-play or engine-guided training.

## Status

Early setup. No agents implemented yet.
